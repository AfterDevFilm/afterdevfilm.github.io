AfterDev - 현상후 개인정보처리방침

시행일: 2026년 11월 2일

1. 앱은 사진과 기록을 밖으로 보내지 않아요

AfterDev는 고르신 현상소 ZIP과 촬영 기록 파일을 휴대폰 안에서만 처리해요. 앱에는 서버가 없고, 사진·기록·사용 정보를 운영자나 다른 곳으로 보내지 않아요. 두 앱 모두 직접 인터넷에 연결하지 않아요. Android 앱은 인터넷 권한 자체가 없어요. iCloud에만 있는 파일이나 사진은 iPhone이 iCloud에서 내려받은 뒤에 읽어요.

2. 휴대폰 안에 남는 것

  • 가져온 롤 목록, 컷 순서, 직접 넣은 촬영 정보는 앱 저장 공간에 남아요.
  • 내보내기를 하면 고르신 사진이 휴대폰 사진 앱에 저장돼요. iPhone에서는 이때 사진 접근 권한을 물어요.
  • 내보낸 사진 파일에는 넣으신 촬영 정보(카메라, 렌즈, 노출, 촬영일 등)가 함께 들어가요. 위치 정보는 넣지 않아요.
  • 앱을 지우면 앱 저장 공간의 기록도 지워져요. 사진 앱에 저장한 사진은 사진 앱에서 직접 지워 주세요.
  • 공유를 누르면 고르신 앱으로 사진이 넘어가고, 그 뒤는 그 앱의 정책을 따라요.

3. 기기 백업

휴대폰 백업(Google 백업, iCloud 백업)이나 새 휴대폰으로 옮기기를 쓰시면 롤 목록 같은 앱 기록이 함께 옮겨질 수 있어요. 미리보기, 모아 보기 그림, 임시 파일은 빠져요. 백업은 각 회사의 정책을 따라요.

4. 오류가 났을 때

자동으로 가는 것: 앱이 갑자기 꺼지면, 기기 설정에 따라 Google Play나 Apple이 충돌 보고를 개발자에게 전해 줄 수 있어요. 앱이 보내는 게 아니라 휴대폰과 스토어가 보내는 것이고, 각 회사의 정책을 따라요. 사진이나 기록은 들어가지 않아요.

직접 올리는 것: 앱의 '제작자에게 알리기'를 누르면 오류 내용(앱 버전, 기기 모델, OS 버전, 컷 번호)이 복사되고 GitHub 페이지가 열려요. 붙여 넣어 올릴지는 직접 정하시고, 올린 글은 공개돼요. 사진, 롤 이름, 파일 이름은 들어가지 않아요.

5. 웹 체험판

afterdevfilm.github.io/try/ 체험판도 브라우저 안에서만 처리하고 사진을 보내지 않아요. 체험판 안의 소감 설문은 Google 설문지로 받으며, 이름과 연락처는 받지 않아요. 사이트는 GitHub Pages에서 운영되며, 접속 기록 같은 호스팅 정보는 GitHub의 정책을 따라요.
